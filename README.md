# Secure QA Lab

A personal training repository for developing hands-on software quality,
test automation, CI/CD, and security-testing skills.

## Current focus

- Python and Pytest
- REST API testing
- SQL backend validation
- Browser automation
- Test-data design
- Git and CI/CD
- Authentication and authorization testing
- Secure software quality practices

## Project rules

- Use only synthetic users and fake test data.
- Do not store passwords, tokens, API keys, or secrets in source control.
- Do not copy employer or client source code, data, documentation, or screenshots.
- Security testing must only be performed against systems I own or am explicitly authorized to test.
- AI-assisted code must be reviewed, executed, understood, and maintainable by me.

## Structure

- "app/" — local demonstration application code
- "tests/unit/" — small isolated tests
- "tests/api/" — REST API tests
- "tests/ui/" — browser automation
- "tests/security/" — authorized identity and security-related regression tests
- "test_data/" — synthetic test inputs
- "reports/" — generated test reports
- "scripts/" — supporting utilities
